# MindNote 지원 페이지

MindNote(하루 한 줄 감정 일기 iOS 앱)의 고객 지원 페이지와 개인정보 처리방침을 담은 저장소입니다. GitHub Pages로 배포되며, App Store의 지원 URL과 개인정보 처리방침 URL로 연결됩니다.

## 페이지

| 페이지 | 주소 | 원본 |
|---|---|---|
| 지원 (FAQ, 문의) | https://m32k.github.io/mindnote-support/ | [index.md](index.md) |
| 개인정보 처리방침 | https://m32k.github.io/mindnote-support/privacy.html | [privacy.md](privacy.md) |

## 수정 방법

`main` 브랜치의 `.md` 파일을 고치면 GitHub Pages가 자동으로 다시 배포합니다(보통 1분 안팎). 개인정보 처리방침을 고칠 때는 본문 위의 **최종 업데이트** 날짜도 함께 바꿔 주세요.
